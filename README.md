# ШАХ · Команда — загрузка приложения

Публичный репозиторий содержит только страницу скачивания и установочные файлы. Исходники приложения и сервера хранятся отдельно в приватных репозиториях.

[Скачать Android APK 0.1.0](https://github.com/ry77cy5y2y-crypto/shah-downloads/releases/download/android-v0.1.0/shah-team-0.1.0.apk).

Для установки откройте файл на Android 8+, подтвердите установку из браузера, затем войдите под личным логином и паролем от администратора. Открытой регистрации нет. APK подписан постоянным ключом выпуска; debug-сборка с другим идентификатором не обновляется этим APK.

iPhone: общедоступная нативная установка пока отсутствует. Нужны Apple Developer, подпись и одобрение App Store. Уже доступна [веб-версия](https://shah-documents.aware-candy-9834.chatgpt.site), которую можно добавить на экран Домой через Safari; это не приложение App Store.

Сохраняйте ключи восстановления переписки перед сменой устройства. Нативные фоновые уведомления/входящие звонки пока не реализованы. Сам факт скачивания не даёт доступа к документам: его проверяет сервер.
