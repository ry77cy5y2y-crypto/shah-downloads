ШАХ · Команда

Рабочее приложение

Скачать приложение может любой. Для работы нужны личные логин и пароль, которые выдаёт администратор. Самостоятельной регистрации нет.

Android

Установочный файл приложения для Android 8 и новее. Подключается к действующему рабочему порталу.

Скачать для Android
Версия 0.1.0 · подписанный APK

Как установить

  1. Скачайте APK и откройте загруженный файл.
  2. Если Android запросит, разрешите установку из этого браузера и нажмите «Установить».
  3. Откройте «ШАХ · Команда» и введите рабочие логин и пароль.

Обновления устанавливаются поверх прежней версии. Не удаляйте приложение ради обновления: в нём могут храниться ключи переписки.

iPhone

Отдельное iPhone-приложение подготовлено к подписи. Ссылка на App Store появится после подключения Apple Developer и одобрения Apple.

Сейчас общедоступной установки нативного iPhone-приложения нет. Неподписанная сборка не устанавливается как обычное приложение.

Доступный сейчас вариант

Рабочий портал можно открыть в Safari. При желании выберите «Поделиться» → «На экран “Домой”». Это веб-версия с иконкой, а не приложение App Store.

Используются те же личные логин и пароль.

Нет учётной записи или не получается войти? Обратитесь к администратору вашей организации. Скачивание приложения само по себе не открывает доступ к рабочим данным.

Для работы нужна сеть. Эта страница не запрашивает пароль. Вход выполняется только в рабочем портале. Нативные фоновые уведомления и звонки в закрытом приложении пока не поддерживаются.
